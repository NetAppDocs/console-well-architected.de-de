Informationen zu den Neuerungen im gut strukturierten Dashboard in der NetApp Console.



[[30-august-2026]]
== 30. August 2026



[[remote-data-replication-assessment-for-cloud-volumes-ontap]]
=== Remote Datenreplizierung Bewertung für Cloud Volumes ONTAP

Eine neue Bewertungsfunktion ist verfügbar, um zu prüfen, ob Cloud Volumes ONTAP Daten durch Remote-Replikation geschützt sind. Dies stellt sicher, dass Ihr Datenschutzplan den Best Practices für Disaster Recovery und Business Continuity entspricht.

link:https://docs.netapp.com/us-en/console-well-architected/cvo/configuration-analysis-cvo.html["Informationen zur Konfigurationsanalyse für Cloud Volumes ONTAP"]



[[dismiss-entire-well-architected-configurations]]
=== Gesamte Well-Architected-Konfigurationen verwerfen

Sie können nun eine gesamte empfohlene Konfiguration aus Ihrem Dashboard ausblenden. Dadurch besteht mehr Kontrolle darüber, welche Empfehlungen und Bewertungen für Ihre Umgebung angezeigt werden.



[[database-workload-recommendations-in-the-well-architected-dashboard]]
=== Empfehlungen für Datenbank-Workloads im Well-Architected Dashboard

Empfehlungen für Datenbank-Workloads mit FSx für ONTAP sind jetzt im Well-Architected Dashboard in der NetApp Console verfügbar. Der Status sowohl Ihrer Speicherressourcen als auch Ihrer Datenbank-Workloads ist an einem Ort einsehbar, was einen vollständigen Überblick über den Zustand Ihrer Infrastruktur ermöglicht.

[[well-architected-issues-displayed-in-netapp-console-systems-page]]
=== Gut strukturierte Probleme werden auf der Seite „NetApp Console Systems“ angezeigt

Benachrichtigungen zu Architekturproblemen sind für Cloud Volumes ONTAP in Microsoft Azure auf der Seite „Storage management Systems“ in der NetApp Console verfügbar. Mit dieser Funktion lassen sich Konfigurationsprobleme in Cloud Volumes ONTAP-Systemen in Azure schnell erkennen und vom Hinweis aus zum Workloads well-architected Dashboard wechseln.

[[google-cloud-netapp-volumes-support-in-the-well-architected-dashboard]]
=== Google Cloud NetApp Volumes Unterstützung im Well-Architected Dashboard

Das NetApp Console Dashboard unterstützt jetzt Google Cloud NetApp Volumes. Speicheradministratoren können den Status ihrer Speicherpools und Konfigurationen einsehen, Empfehlungen zur Verbesserung von Effizienz, Kosten, Leistung, Zuverlässigkeit und Sicherheit erhalten sowie Maßnahmen zur Optimierung des Betriebs und zur Einhaltung bewährter Verfahren ergreifen.

Weitere Informationen zu link:https://docs.netapp.com/us-en/console-well-architected/gcnv/configuration-analysis-gcnv.html["Konfigurationsanalyse für Google Cloud NetApp Volumes"].



[[03-august-2026]]
== 03. August 2026



[[fix-dismiss-and-reactivate-configurations-for-cloud-volumes-ontap-in-microsoft-azure]]
=== Konfigurationen für Cloud Volumes ONTAP in Microsoft Azure beheben, verwerfen und reaktivieren

Das übersichtliche Dashboard in NetApp Console bietet jetzt die Möglichkeit, Konfigurationsempfehlungen für Ihre Cloud Volumes ONTAP Systeme zu beheben.

Sie können auch eine oder mehrere Konfigurationen von der Analyse der optimalen Architektur ausschließen. Dadurch ist es möglich, bestimmte Konfigurationen zu ignorieren, die für Ihre Umgebung nicht zutreffen.

Wenn Sie eine verworfene Konfiguration später wieder einbinden möchten, können Sie sie im Well-Architected Dashboard reaktivieren. Dadurch wird die Konfiguration in die Analyse zurückgeholt und es werden Empfehlungen und Korrekturen dafür bereitgestellt.

link:https://docs.netapp.com/us-en/console-well-architected/cvo/\improve-configurations-cvo.html["Konfigurationen für Cloud Volumes ONTAP in Microsoft Azure beheben, verwerfen und reaktivieren"]



[[20-july-2026]]
== 20. Juli 2026



[[introducing-the-well-architected-dashboard-in-netapp-console]]
=== Einführung des gut strukturierten Dashboards in der NetApp Console

Das übersichtliche Dashboard in der NetApp Console bietet eine zentrale Übersicht über Ihre Speichersysteme und Konfigurationen über alle Konten und Regionen hinweg. Das Dashboard liefert Einblicke und Empfehlungen, die zur Erreichung optimaler Betriebsabläufe beitragen. Der Well-Architected-Status Ihrer Konfigurationen, Konfigurationsprobleme, die nach den Säulen des Well-Architected-Frameworks für den von Ihnen verwendeten Speichertyp organisiert sind, sowie eine Liste von Konfigurationsproblemen und Empfehlungen werden angezeigt.

Erfahren Sie mehr über das link:https://docs.netapp.com/us-en/console-well-architected/learn-well-architected-dashboard.html["gut gestaltetes Dashboard"].

Das übersichtliche Dashboard in der Konsole ist verfügbar für link:https://docs.netapp.com/us-en/console-well-architected/cvo/configuration-analysis-cvo.html["Cloud Volumes ONTAP in Microsoft Azure."]



[[build-your-own-custom-rules]]
=== Eigene benutzerdefinierte Regeln erstellen

Benutzerdefinierte Regeln können in einfacher Sprache erstellt werden, damit Ihre Systeme den Standards Ihres Unternehmens und den NetApp Best Practices entsprechen. Die Regeln lassen sich mit einem Probelauf testen und anschließend für die Ausführung in Ihren Umgebungen einplanen.

https://docs.netapp.com/us-en/console-well-architected/learn-custom-rules.html["Weitere Informationen zu benutzerdefinierten Regeln"]
