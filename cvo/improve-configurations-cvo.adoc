= Gut strukturierte Cloud Volumes ONTAP Systemkonfigurationen implementieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Mit Erkenntnissen und Empfehlungen aus der Konfigurationsanalyse lässt sich NetApp nutzen, um Best Practices für Ihre Cloud Volumes ONTAP Systeme auf Microsoft Azure Storage umzusetzen. Der gut konzipierte Status kann einfach überprüft werden, Informationen zu Problemen mit Ihren Konfigurationen stehen zur Verfügung, und Empfehlungen zur Verbesserung der Architektur von Systemen, die nicht auf Zuverlässigkeit, Sicherheit, Effizienz, Leistung und Kosten optimiert sind, werden bereitgestellt.

link:configuration-analysis-cvo.html["Informationen zur Konfigurationsanalyse und zum Well-Architected-Status."]



[[about-this-task]]
== Über diese Aufgabe

Das Well-Architected-Dashboard analysiert täglich die Bereitstellungskonfigurationen des Cloud Volumes ONTAP Systems auf Microsoft Azure. Die tägliche Analyse liefert den Well-Architected-Status, Einblicke und Empfehlungen.

Die Verbindung über Link oder den Konsolenagenten ermöglicht es dem übersichtlichen Dashboard in der NetApp Console, Ihre Cloud Volumes ONTAP Systeme umfassend auf Probleme mit Leistung, Datenschutz und Konfigurationen zu überprüfen. Dadurch werden präzise Einblicke und Empfehlungen zur Optimierung Ihrer Cloud Volumes ONTAP Systeme bereitgestellt.

Die Anforderungen an die Speicherkonfiguration variieren. Die Analyse spezifischer Konfigurationen, die für Ihre Speicherumgebung nicht relevant sind, kann ausgeblendet werden. So werden unnötige Warnmeldungen und ungenaue Optimierungsergebnisse vermieden.



[[before-you-begin]]
== Bevor Sie beginnen

* Sie müssen link:https://console.netapp.com/add-working-environment/choose-type["Ein Cloud Volumes ONTAP System hinzufügen"] zur NetApp Console wechseln, um den Status der gut strukturierten Konfiguration und Empfehlungen für Konfigurationsprobleme anzuzeigen.
* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html["Es empfiehlt sich, einen Console Agent bereitzustellen."] für die umfassendste Analyse Ihrer Systemressourcen.




[[view-recommendations-for-configuration-issues]]
== Empfehlungen zu Konfigurationsproblemen anzeigen

Nach Abschluss der täglichen Analyse können Sie Empfehlungen zu Konfigurationsproblemen einsehen. Empfehlungen erläutern bewährte Vorgehensweisen und potenzielle Risiken nicht optimierter Konfigurationen. Es besteht außerdem die Möglichkeit, eine CSV-Datei mit den Empfehlungen herunterzuladen.

.Schritte
. Melden Sie sich bei der link:https://console.netapp.com/home["NetApp Console"^] an.
. Wählen Sie im NetApp Console-Menü die Option *Workloads* und dann *Well-architected* aus.
. Im Dashboard „Well-architected“ kann für jede Konfiguration die Option *Ansicht* ausgewählt werden.
+
Optional kann image:button_download.png["Ein Screenshot des Download-Symbols"]eine CSV-Datei mit den Empfehlungen für alle Konfigurationen heruntergeladen werden.

. Die Empfehlung wird überprüft.




[[fix-a-configuration-issue]]
== Ein Konfigurationsproblem beheben

Sie können Konfigurationsprobleme für ein Cloud Volumes ONTAP System oder für ausgewählte Volumes in einem Dateisystem beheben. Es besteht die Möglichkeit, eine oder mehrere Konfigurationen zur Behebung auszuwählen.

Der Behebungsprozess kann zu Instanz-Ausfallzeiten oder Serviceunterbrechungen führen. Jede Empfehlung sollte sorgfältig geprüft werden, bevor ein Konfigurationsproblem behoben wird.

.Schritte
. Melden Sie sich bei der link:https://console.netapp.com/home["NetApp Console"^] an.
. Wählen Sie im NetApp Console-Menü die Option *Workloads* und dann *Well-architected* aus.
. Im Dashboard „Well-architected“ kann für jede Konfiguration die Option *Ansicht* ausgewählt werden.
+
Stellen Sie sicher, dass Sie die Empfehlung sorgfältig überprüfen. Die Empfehlung erläutert bewährte Vorgehensweisen und potenzielle Fallstricke nicht optimierter Konfigurationen.

. *Reparieren* auswählen.
+
Wenn *Anzeigen und Reparieren* eine Option ist, die betroffenen Volumes zur Behebung auswählen.

. In der Zusammenfassung und den im Dialogfeld angezeigten Maßnahmen wird dargestellt, was geschieht, wenn das Problem behoben wird. Einige Vorgänge können zu Ausfallzeiten der Instanz oder zu Dienstunterbrechungen führen.
. *Weiter* auswählen, um das Konfigurationsproblem zu beheben.


.Ergebnis
Workload Factory startet den Prozess zur Behebung des Problems. Im Menü „Kontoeinstellungen“ die Option *Tracker* auswählen, um den Status des Vorgangs anzuzeigen.



[[dismiss-a-configuration-analysis]]
== Konfigurationsanalyse verwerfen

Eine Konfigurationsanalyse für ein Cloud Volumes ONTAP System oder für ausgewählte Volumes kann gestoppt werden. Die Analyse kann bei Bedarf neu gestartet werden.

[role="tabbed-block"]
====
.Eine Konfigurationsanalyse für ein System ablehnen
--
.Schritte
. Melden Sie sich bei der link:https://console.netapp.com/home["NetApp Console"^] an.
. Wählen Sie im NetApp Console-Menü die Option *Workloads* und dann *Well-architected* aus.
. Im Dashboard „Well-architected“ kann für jede Konfiguration die Option *Ansicht* ausgewählt werden.
. Suchen Sie unter Configurations die Konfiguration, die nicht auf Ihre Umgebung zutrifft, und wählen Sie dann *Dismiss*.
. Im Dialogfeld „Konfiguration verwerfen“ *Verwerfen* auswählen, um die Konfigurationsanalyse zu beenden.


--
.Eine Konfigurationsanalyse für ein Volume abbrechen
--
.Schritte
. Melden Sie sich bei der link:https://console.netapp.com/home["NetApp Console"^] an.
. Wählen Sie im NetApp Console-Menü die Option *Workloads* und dann *Well-architected* aus.
. Im Dashboard „Well-architected“ kann für jede Konfiguration die Option *Ansicht* ausgewählt werden.
. Unter „Konfigurationen“ identifizieren Sie die Konfiguration, die für die ausgewählten Volumes verworfen werden soll, und wählen Sie dann *Anzeigen und reparieren* aus.
. Die Volumes, die aus der Konfigurationsanalyse ausgeschlossen werden, identifizieren.
+
** Für ein Volume: das Menü „Aktionen“ auswählen und dann *Volume ausblenden* auswählen.
** Für mehrere Volumes: Die Volumes auswählen und dann neben *Bulk action* auf *Dismiss* klicken.


. *Verwerfen* auswählen, um die Analyse für die Konfiguration zu beenden.
. Im Dialogfeld „Volumes verwerfen“ *Verwerfen* auswählen, um zu bestätigen.


--
====
.Ergebnis
Die Konfigurationsanalyse stoppt für das System oder die ausgewählten Volumes.

Sie können die Analyse jederzeit reaktivieren.



[[reactivate-a-dismissed-configuration-analysis]]
== Eine verworfene Konfigurationsanalyse reaktivieren

Eine verworfene Konfigurationsanalyse für ein Cloud Volumes ONTAP System kann jederzeit reaktiviert werden. Eine oder mehrere Konfigurationen können zur Reaktivierung ausgewählt werden.

[role="tabbed-block"]
====
.Eine Konfigurationsanalyse für ein System reaktivieren
--
.Schritte
. Melden Sie sich bei der link:https://console.netapp.com/home["NetApp Console"^] an.
. Wählen Sie im NetApp Console-Menü die Option *Workloads* und dann *Well-architected* aus.
. Wählen Sie *Verworfene Konfigurationen* aus.
. Die gewünschte Konfiguration auswählen und *Reaktivieren* wählen.


--
.Eine Konfigurationsanalyse für ein Volumen reaktivieren
--
.Schritte
. Melden Sie sich bei der link:https://console.netapp.com/home["NetApp Console"^] an.
. Wählen Sie im NetApp Console-Menü die Option *Workloads* und dann *Well-architected* aus.
. Wählen Sie *Verworfene Konfigurationen* aus.
. Das/die zu reaktivierende(n) Volumen wird/werden anhand der Konfigurationsanalyse identifiziert.
+
** Für ein Volume: Wählen Sie das Aktionsmenü und dann *Volume reaktivieren*.
** Für mehrere Volumes: Die Volumes auswählen und dann neben *Massenaktion* auf *Reaktivieren* klicken.




--
====
.Ergebnis
Das System reaktiviert die Konfigurationsanalyse. Täglich findet eine neue Analyse statt.
